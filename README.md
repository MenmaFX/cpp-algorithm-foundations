# 🚀 C++ & Algoritma Dasar (Roadmap Kuliah Semester 1)

Repositori ini berisi dokumentasi dan kode latihan mandiri persiapan kuliah Informatika, difokuskan pada penguasaan sintaks dasar C++, manipulasi memori, serta logika komputasi.

## 📚 Daftar Modul Latihan

- **`01-kerangka-dasar-dan-output/`**: Struktur awal program C++, fungsi `main()`, dan perintah cetak layar (`std::cout`).
- **`02-newline-dan-output-teks/`**: Manipulasi baris teks menggunakan `\n` dan `std::endl`.
- **`03-variabel-dan-tipe-data-dasar/`**: Pengenalan variabel penampung data (`int`, `double`, `string`).
- **`04-input-data-dengan-cin/`**: Program interaktif dengan masukan keyboard user (`std::cin`).

## 🛠️ Lingkungan Pengembangan
- **Bahasa:** C++ (Standar C++17/C++20)
- **Kompiler Rekomendasi:** G++ / MinGW / Clang
